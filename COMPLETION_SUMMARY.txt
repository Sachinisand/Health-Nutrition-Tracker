## 🚀 Ready to Use! (3 Steps)

### Step 1: Install Dependencies
```bash
pip install -r requirements.txt
```

### Step 2: Set Up API Key (Optional but Recommended)
```
Create .env file:
GEMINI_API_KEY=your_key_from_aistudio.google.com
```

### Step 3: Run the App
```bash
streamlit run app.py
```
